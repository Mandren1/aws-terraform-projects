# AWS Cloud Project 1: AWS Infrastructure Fundamentals

This project introduces the fundamentals of deploying AWS infrastructure using Terraform.

The infrastructure includes an Amazon EC2 instance running an Nginx web server, a Security Group controlling HTTP and SSH traffic, and an Amazon S3 bucket. The EC2 instance is automatically configured using Terraform User Data.

## Technologies Used

- Terraform
- Amazon EC2
- Amazon S3
- AWS Security Groups
- Nginx
- Amazon Linux 2023

## Key Takeaway

The purpose of this project was to get familiar with Terraform and how it can be used to deploy and manage resources in AWS.

Best practices were not the main focus. Instead, I used this project to build foundational experience that I could apply in my upcoming AWS projects. 

This project was intended to be extremely short and straight to the point. Therefore, no screenshots are included in this README.
