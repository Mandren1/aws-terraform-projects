# AWS Terraform Projects

This repository contains three AWS infrastructure projects built with Terraform. The projects were created progressively to develop practical experience with AWS, Terraform, networking, scalability, security, and database integration.

Project 3 is the most comprehensive project in this repository and contains a more detailed README with architecture documentation and screenshots.

## Project 1: AWS Infrastructure Fundamentals
Introduction to Terraform and AWS infrastructure provisioning using EC2, S3, Security Groups, and Nginx.

## Project 2: Custom VPC and Networking
Expands on the first project by introducing a custom VPC, public and private subnets, routing, and a more structured Terraform configuration.

## Project 3: Highly Available AWS Web Architecture
Combines the concepts from the previous projects into a more advanced architecture using multiple Availability Zones, Application Load Balancing, Auto Scaling, RDS PostgreSQL, IAM, Secrets Manager, and Systems Manager.
